# Shrink-X Pro Download Page

Mobile-friendly landing page for Shrink-X Pro — Image & PDF Compressor.

The **Download Now** button opens the official Google Play listing:
https://play.google.com/store/apps/details?id=com.imagecompressor.image_compressor_resizer

Users install the app on Google Play; this website does not install apps directly.

## GitHub Pages
This repository includes a GitHub Actions workflow that publishes the site when files are pushed to the `main` branch. If Pages is not already enabled for Actions, open **Settings → Pages** and choose **GitHub Actions** as the build and deployment source.

After the first successful deployment, the site should be available at:
https://utkarshydv27.github.io/ShrinkX-Pro-Download-Page/

Note: This landing page may help route visitors to the Play Store, but it cannot guarantee Instagram will open every destination.
